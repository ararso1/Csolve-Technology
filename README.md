# Csolve Technology

Company website for **Csolve Technology** — IT solutions, services, and contact — built with Next.js 14 and React.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Create production build  |
| `npm start`     | Run production server    |
